# Statistics for Data Analysis Nanodegree Program

This repository contains projects completed as part of the **Udacity Statistics for Data Analysis Nanodegree Program**. These projects apply core statistical concepts including descriptive statistics, probability, hypothesis testing, A/B testing, and linear regression.

## Setup

```bash
git clone https://github.com/polarbeargo/Statistics-for-Data-Analysis-Nanodegree-Program.git
cd Statistics-for-Data-Analysis-Nanodegree-Program
```

Create and activate a Python virtual environment:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install jupyter pandas numpy matplotlib seaborn scipy scikit-learn
```

Then launch Jupyter Notebook from the project root:

```bash
jupyter notebook
```

## Projects

### 1. Describe Health and Sleep Quality Data
This project explores a dataset related to health and sleep quality using descriptive statistics and data visualization. The goal is to summarize the data, identify patterns, and communicate findings clearly.

Presentation:  
[Describe Health and Sleep Quality Data](https://docs.google.com/presentation/d/1ks_KEI0_katneRk448EuZF3y7o4mnoM_Cu7hOSIMWYU/edit?usp=sharing)

Notebook:  
[sleep.ipynb](Describe%20Health%20and%20Sleep%20Quality%20Data/sleep.ipynb)

### 2. Calculate Basketball Scoring Probabilities
This project analyzes basketball shooting data using probability concepts. It includes calculating overall probabilities, conditional probabilities, and applying Bayes’ Theorem to interpret Steph Curry’s shooting statistics.

Presentation:  
[Calculate Basketball Scoring Probabilities](https://docs.google.com/presentation/d/1ErSSbBIouU982xWzn7q7DFqjjsqRPvpB1YFdAg1Mvm8/edit?usp=sharing)

Notebook:  
[steph_shooting_probabilities.ipynb](Calculate%20Basketball%20Scoring%20Probabilities/steph_shooting_probabilities.ipynb)

### 3. Analyze A/B Test Results
This project investigates the results of an A/B test using statistical inference. It focuses on hypothesis testing, p-values, and decision-making based on experimental data.

Presentation:  
[Analyze A/B Test Results](https://docs.google.com/presentation/d/15dVT-RuEAU5rbW8DXeI-6GgqOeI33ww9F57I9KWCzk8/edit?usp=sharing)

Notebook:  
[analyze_ab_test_results_project.ipynb](Analyze%20A%3AB%20Test%20Results/analyze_ab_test_results_project.ipynb)

### 4. Model Salary Data with Linear Regression
This project uses linear regression techniques to model salary data and examine relationships between variables. It demonstrates how regression can be used for prediction and interpretation.

Presentation:  
[Model Salary Data with Linear Regression](https://docs.google.com/presentation/d/1b0cqE8HIGB3n0pK6JFt5lIixlu45NhAldQePTv7dcE0/edit?usp=sharing)

Notebook:  
[salary_prediction_project.ipynb](Model%20Salary%20Data%20with%20Linear%20Regression/salary_prediction_project.ipynb)
